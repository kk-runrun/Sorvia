# 超级策划 Super Planner

**面向跨境电商团队的 AI 策划稿生成工作流。**

超级策划不是一个简单的 Listing 文案生成器，而是一套从 **产品资料 → 市场研究 → 策略策划 → 文案生成 → QA质检 → 策划稿输出** 的完整策划工作流。

它将跨境电商大卖团队实际使用的策划思路、产品规格书处理、市场研究、卖点判断、Amazon 文案规则和 QA 机制整合到一个统一流程中。

用户只需要提供：

- 产品关键词
- 产品概述
- 产品规格书

系统即可自动完成后续策划流程，并最终生成可供策划、运营和文案人员继续审核、精修和执行的 Excel 策划稿。

---

# 核心理念

传统 AI Listing 工具通常是：

`输入关键词 → 直接生成文案`

超级策划采用的是另一条路线：

```text
产品事实
    ↓
市场研究
    ↓
用户需求
    ↓
竞争格局
    ↓
购买理由
    ↓
卖点优先级
    ↓
内容规划
    ↓
Listing文案
    ↓
QA质检
    ↓
策划稿
